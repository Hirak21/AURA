# Documentation set — AURA v3.0

Two files sit at the **repository root** because coding agents look for them there:

- [`../agent.md`](../agent.md) — implementation contract (layering law, framework traps, definition of done)
- [`../design.md`](../design.md) — design system (monochrome + scoped gold, components, writing style)

Everything else lives here:

| File | Read it when |
|---|---|
| [`PRD.md`](PRD.md) | You need scope, requirements, acceptance criteria, or the honest boundary list |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | You are changing data models, transactions, security, or deployment |
| [`ADAPTATION-RULES.md`](ADAPTATION-RULES.md) | You are touching the recommendation rules or progress states |
| [`QA.md`](QA.md) | You need to know what has actually been verified (and what has not) |
| [`DEMO-SCRIPT.md`](DEMO-SCRIPT.md) | You are presenting to judges |
| [`SEED-DATA.md`](SEED-DATA.md) | You are changing demo data or wondering why a record exists |
| [`DECISIONS.md`](DECISIONS.md) | You are about to re-open a settled question |
